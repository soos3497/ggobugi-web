# 꼬북이 · 물리치료 평가 기록지 (웹)

**사이트: https://ggobugi-web.vercel.app**

물리치료 평가 기록지(10주차 최신판)를 웹사이트로 쓰기 위한 저장소입니다. 모든 가상 환자는 교육·실습용입니다.

## 화면 흐름
1. **환자 선택** — 기본 환자 `김민수(가상)` + 가상 환자 추가(빈 양식 / 기존 시나리오 01·02·03으로 시작)
2. **목차** — 1. 검진 ~ 7. 결과. `세부`를 누르면 A-1~A-12, C-1~C-15, 4-1~4-6, ①~⑥ 같은 항목이 펼쳐짐
3. **영역 보기** — 고른 단계의 기록지만 보여 줌. 맨 위 `← 목차` 단추, 맨 아래 이전/다음 단계 막대. 브라우저 뒤로가기도 동작
- 조작키는 기록지 그대로: `1` 작성 막대 · `2` 목차 바로가기 · `3` 꽉 찬 화면 · `4` 직전 수정 밑줄 · `Tab` 누르고 있기 = 조작법
- 긴 글 문단은 접혀 있다가 눌러서 펼침, 긴 입력칸은 누르면 펼쳐지고 다른 곳을 누르면 다시 접힘

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 기록지 본문 = `꼬북이.html`(10주차 최신판) **그대로** + `<head>` 맨 앞 3줄(아래 두 파일 연결) |
| `web/shell.js` | 환자 선택·목차·영역 보기·환자별 기록 보관 |
| `web/shell.css` | 위 화면들의 모양 |

**기록지 내용(항목·문구·판정 로직·순서)은 바꾸지 않습니다.** 화면 틀은 `web/` 두 파일에만 있습니다.

### 기록지 본문을 새 판으로 바꿀 때
새 `꼬북이.html` 의 `<head>` 안 viewport 줄 바로 아래에 아래 3줄을 넣어 `index.html` 로 저장하면 됩니다. (맨 앞에 있어야 첫 화면이 기록지보다 먼저 뜸)
```html
<!-- 꼬북이 웹 껍데기: 환자 선택 · 목차 · 영역 보기 (기록지 내용은 위 그대로) -->
<link rel="stylesheet" href="web/shell.css">
<script src="web/shell.js"></script>
```

## 저장
- 환자 목록: 브라우저 localStorage `ggobugi_web_patients`
- 환자별 기록: localStorage `ggobugi_web_snap_<환자id>` (기록지의 JSON 백업 형식 그대로, 15초마다·화면 이동 때 자동 보관)
- 기록은 **그 브라우저에만** 남습니다. 다른 컴퓨터로 옮길 때는 기록지 위쪽 `💾 JSON 백업` / `📂 JSON 복원`.

## 배포
정적 사이트(빌드 없음). Vercel 프로젝트 `ggobugi-web` 에 연결돼 있어 **main 에 push 하면 자동으로 다시 배포**됩니다.

## 학과 연계
- **학과 테마 키트**(`web/univ-kit/`, 교수님 학습 포털 앱들이 함께 쓰는 키트에서 가져옴): 환자 선택·목차 화면에만 상단 띠·캠퍼스 배너·하단 정보 모양을 적용. 기록지 화면 모양은 그대로.
- **학과 표준 설문도구**(https://pt-questionaires.vercel.app/): 목차 아래 '연계 도구'에서 부위별로 새 창으로 열림. 의뢰 진단명으로 부위를 골라 '이 환자 추천' 표시. 설문 결과가 기록지로 자동으로 들어오지는 않음.

## 랜덤 가상환자 만들기
- 환자 선택 화면의 **🎲 가상 환자 만들기**: 이름·나이·성별·직업·질환·심한 정도·발병 시기·아픈 쪽·기타사항을 고르거나(빈칸은 랜덤) "전부 랜덤"으로 채운 뒤 "환자 만들기".
- 질환(환자 유형): 목 통증·전방머리자세 / 허리 통증 / 어깨 통증(회전근개) / 무릎 골관절염 / 발목 염좌는 `web/gen/gen.js` 의 틀로 기록지 전체를 채움(심한 정도·아픈 쪽·나이·직업·기타사항 반영). 뇌졸중·척수손상은 기록지 예시 환자를 바탕으로 이름·나이·성별·직업만 바꿈.
- 기록지의 칸·문구는 바꾸지 않고 기록지에 들어 있는 입력 함수로 값만 넣음.

## 교수님 안내서(AIDX 중재·결과) 보완 — `web/addons.js`
- ⑥ 중재 > ② 중재 근거 검색: **➕ 근거 직접 추가** — PMID·DOI로 PubMed/Crossref 실제 서지 불러오기(실패 시 실패 표시, 지어내지 않음), 진료지침·교과서·학회 권고 직접 입력 → 근거 목록에 저장.
- 7 결과: **신경학적 재검사(감각·반사·근력)** 표 — 초기값은 기록지 C-5·C-6·C-7에서 읽고, 4주·8주는 직접 선택(미측정 기본), 악화 시 재검진 검토 경고. 환자별 localStorage `ggobugi_web_neuro_<환자id>`.
- index.html(기록지)은 바꾸지 않고 shell.js 가 이 파일을 불러옴.
- ② 검색 결과·KCI 미리보기·근거 목록: **연구 방법 정리**(① 연구대상 ② 연구기간 ③ 실험·중재·연구 방법 ④ 통계 방법) — 초록 구분 제목과 문장 단서어로 자동 분류(정확하지 않을 수 있음 표시), 없으면 '보고되지 않음/원문 확인 필요'. 근거 목록에서는 [근거 칸에 채우기(빈 칸만)]로 연구 대상·추적기간·중재군 칸에 옮김.
- ⑤·⑥·7 결과: **🧪 가상 경과 시나리오 만들기(연습용)** — 순조로운 호전/느린 호전/중간 악화 후 회복 중 골라 ⑤ 회기 8회(4·8회기 재평가)·④ 교육 확인·⑥ 결정·7 결과 중간/종료값(기록지의 '회기 기록에서 가져오기' 사용)을 채움. 모든 화면에 '가상 경과(연습용) — 실제 측정값 아님' 표시, [가상 경과 지우기]로 되돌림. 직접 기록한 회기가 있으면 만들지 않음. (교수님 안내서는 실제 값만 쓰라고 하므로 제출용에서는 지우고 낼 것)
- ⑥ 중재 > ③ 중재 카드: **FITT-VP 한눈에 보기** — 카드의 용량 표(학생 제안 → 없으면 논문 용량)와 ⑤ 진행·감량 기준을 F 빈도·I 강도·T 시간·T 종류·V 총량(반복×세트×주당 빈도, 회당 분×빈도 자동 계산)·P 진행 6칸으로 모아 보여 줌. 읽기 전용(새 입력칸 없음), 표를 고치면 바로 바뀜.
