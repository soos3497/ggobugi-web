# 꼬북이 · 물리치료 평가 기록지 (웹)

**사이트: https://ggobugi-web.vercel.app**

물리치료 평가 기록지(10주차 최신판)를 웹사이트로 쓰기 위한 저장소입니다. 모든 가상 환자는 교육·실습용입니다.

## 화면 흐름
1. **환자 선택** — 기본 환자 `김민수(가상)` + 가상 환자 추가(빈 양식 / 기존 시나리오 01·02·03으로 시작)
2. **목차** — 1. 검진 ~ 7. 결과. `세부`를 누르면 A-1~A-12, C-1~C-15, 4-1~4-6, ①~⑥ 같은 항목이 펼쳐짐
3. **영역 보기** — 고른 단계의 기록지만 보여 줌. 맨 위 `← 목차` 단추, 맨 아래 이전/다음 단계 막대. 브라우저 뒤로가기도 동작
- 조작키는 기록지 그대로: `1` 작성 막대 · `2` 목차 바로가기 · `3` 꽉 찬 화면 · `4` 직전 수정 밑줄 · `Tab` 누르고 있기 = 조작법
- 긴 글 문단은 접혀 있다가 눌러서 펼침, 긴 입력칸은 누르면 펼쳐지고 다른 곳을 누르면 다시 접힘

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 기록지 본문 = `꼬북이.html`(10주차 최신판) **그대로** + 맨 끝 3줄(아래 두 파일 연결) |
| `web/shell.js` | 환자 선택·목차·영역 보기·환자별 기록 보관 |
| `web/shell.css` | 위 화면들의 모양 |

**기록지 내용(항목·문구·판정 로직·순서)은 바꾸지 않습니다.** 화면 틀은 `web/` 두 파일에만 있습니다.

### 기록지 본문을 새 판으로 바꿀 때
새 `꼬북이.html` 의 마지막 `</body>` 바로 앞에 아래 3줄을 넣어 `index.html` 로 저장하면 됩니다.
```html
<!-- 꼬북이 웹 껍데기: 환자 선택 · 목차 · 영역 보기 (기록지 내용은 위 그대로) -->
<link rel="stylesheet" href="web/shell.css">
<script src="web/shell.js"></script>
```

## 저장
- 환자 목록: 브라우저 localStorage `ggobugi_web_patients`
- 환자별 기록: localStorage `ggobugi_web_snap_<환자id>` (기록지의 JSON 백업 형식 그대로, 15초마다·화면 이동 때 자동 보관)
- 기록은 **그 브라우저에만** 남습니다. 다른 컴퓨터로 옮길 때는 기록지 위쪽 `💾 JSON 백업` / `📂 JSON 복원`.

## 배포
정적 사이트(빌드 없음). Vercel 프로젝트 `ggobugi-web` 에 연결돼 있어 **main 에 push 하면 자동으로 다시 배포**됩니다.
